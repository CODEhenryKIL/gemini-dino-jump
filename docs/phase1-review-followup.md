# 1차 자동 리뷰 후 추가 수정

작성일: 2026-09-25. 브랜치: `codex/phase1-review-fixes`. 기준: PR #3 병합 커밋 `7955f4462098ca8b5486db1e3cbd3d7855779d79`.

## 경위

사용자 승인으로 1차 구현과 F1–F3 보완을 [PR #3](https://github.com/CODEhenryKIL/gemini-dino-jump/pull/3)으로 main에 병합했다. 당시 Python 123개·Node 35개 검사가 통과했으나, 병합 직후 완료된 Copilot 리뷰가 추가 결함을 지적했다. 기존 검사가 놓친 경로를 보완하며, 기존 통과 기록을 무결함의 근거로 간주하지 않는다.

## 수정과 검증 범위

| 항목 | 수정 | 회귀 검증 |
| --- | --- | --- |
| 충돌 없는 점수 승인 | 재시뮬레이션에서 충돌을 확인하지 못하면 `NO_COLLISION`으로 거절 | 충돌 검사를 대역으로 제어해 기존 잘못된 승인 경로 확인, 수정 후 HTTP 422·랭킹 미등록·복주머니 잠금·REJECTED 저장 검증 |
| 숫자·입력 타입 강제 변환 | 점수·tick을 정수로 강제 변환하지 않고 원래 JSON 타입 검사, high 점프는 bool만 허용 | 소수·문자열·bool·NaN/Infinity 거절, 잘못된 요청 후 ACTIVE 유지, 정상 충돌 seed 4개 통과 |
| 닉네임 변경 시 공개 설정 | 프론트는 nickname만 전송, 서버는 생략된 is_public을 잠근 행의 현재값으로 보존 | 공개·비공개 각각 실제 HTTP/DB 보존, 명시적인 bool 변경 허용, 잘못된 값 거절 |
| 공유 통계 | native 공유 미지원 시 실제 copy 시도·결과만 기록 | 복사 성공·실패, native 취소, 허위 native 시도 미발생 확인 |
| 초대 링크 유입 정보 | 로컬 리디렉션에서 검증된 link/share/channel/campaign 보존, 초대 코드 길이 12–64자 통일 | 허용값 유지, 잘못된 값·알 수 없는 필드·invite 덮어쓰기 제거, Vercel 경로 규칙 확인 |

점수 문제의 확정 근거는 코드 경로와 충돌 검사를 제어한 회귀 테스트다. 제한된 실제 물리 입력 탐색으로 36,000 tick 전체의 무충돌 입력을 확보하지 못했으므로, 실제 악용 전체 재현을 완료했다고 주장하지 않는다. 물리 엔진·점수 공식·기존 충돌 허용 오차는 변경하지 않았다.

독립 검토에서 최초 프론트 수정만으로는 서버가 is_public 필수값을 거절한다는 계약 불일치를 발견했다. 서버 PATCH와 문서를 함께 고치고 실제 HTTP/DB 통합 검사를 추가했다. 프론트 대역 테스트만으로 서버 연결을 검증했다고 간주하지 않는다.

## 최종 로컬 검증

- Python 전체 회귀: 131개 통과, 실패·건너뜀 없음. [결과](evidence/phase1-review-python.txt)
- Node 전체 회귀: 39개 통과, 실패·건너뜀 없음. [결과](evidence/phase1-review-node.txt)
- Python compileall, 변경 JavaScript 구문, Git diff whitespace 검사 통과.
- 로컬 PostgreSQL 회귀이며 원격 부하 시험은 추가로 실행하지 않았다.

## 반영 경계

- 사용자 요청에 따라 추가 수정도 브랜치 푸시·PR·main 병합 대상으로 처리한다.
- 이번 변경은 원격 Supabase 설정·데이터·Vercel 설정·배포를 변경하지 않는다. 기존 Preview는 이전 배포본이다.
- F1 수령 상태 migration은 원격 미적용 상태다. 향후 배포 전에 해당 migration과 필수 스키마 버전을 맞춰야 한다.
- 이번 추가 수정의 실제 Preview 브라우저 검증은 미실행이다. 기존 200명 시험의 p95 목표 미달과 스테이지 전환 끊김도 미해결 후속 항목으로 유지한다.
- 초대 링크 유입값 보존은 로컬 HTTP 리디렉션으로 검증했다. Vercel은 정적 rewrite를 사용하므로 실제 배포에서 query 값이 유지되는지는 배포 후 별도 확인이 필요하다.
