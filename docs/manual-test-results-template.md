# 수동 테스트 실행 기록 양식

이 파일을 실행별로 복사한다. 기본 값은 실행 완료를 뜻하지 않는다. 담당자와 증거가 없는 항목을 통과로 표시하지 않는다. 공개 Git 저장 전 개인정보와 인증값을 제거한다.
