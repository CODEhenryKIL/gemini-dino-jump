## 배포 직전 기준 재집계와 후속 추적

2026-09-29 22:14:59 KST에 생성 시각을 기준으로 **배포 확인 시각인 22:11:08 직전까지**의 기록을 재집계했다. 앞서 21:59에 기록한 37.78%는 그 시각의 관측값이며, 배포 직전 기준값은 다음과 같다.

| 집단 | 전체 참가자 | 추첨 참가자 | 추첨 비율 | 유효 게임 완료 | 게임 완료자 중 추첨 비율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 배포 직전까지 | 150 | 60 | **40.00%** | 109 | **55.05%** |
| 배포 이후 신규 참가자, 22:14:59 현재 | 8 | 1 | 12.50% | 5 | 20.00% |
| 전체 누적, 22:14:59 현재 | 158 | 61 | 38.61% | 114 | 53.51% |

- 배포 직전 미추첨: **90명 / 150명 = 60.00%**.
- 배포 이후 집단은 참가자 생성 시각이 22:11:08 이상인 사람만 포함한다. 기존 참가자의 늦은 추첨을 신규 집단의 성과에 섞지 않는다.
- 새 집단은 생성 후 4분도 지나지 않아 위 비율로 개선 효과를 판단할 수 없다.
- 동일한 관찰 시간을 맞추기 위해 **참가자 생성 후 30분 이내 첫 추첨 비율**을 추가 집계한다. 30분이 지난 참가자만 분모에 포함한다.
- 배포 전 30분 관찰 가능 집단은 89명 중 36명, **40.45%**. 배포 후 30분 관찰 가능 집단은 현재 0명이므로 비율은 미집계이며 0%로 표시하지 않는다.
- 비교는 유입 시각 기준이며 사용자별 실제 화면 버전 노출을 증명하지 않는다. 새로고침하지 않은 기존 탭과 유입 채널 차이가 있어 인과 효과를 확정할 수 없다.
- 기존 **공룡 점프 행사 10분 현황** 자동화에 추첨 비율 집계를 추가한다.
- [재현 가능한 읽기 전용 집계 SQL](sql/pouch-ux-conversion.sql) · [추적 시작 원본](evidence/pouch-ux-tracking-start-20260929.json)

## 해석 범위

- 참가자 ID는 브라우저 쿠키 기준이다. 동일인이 다른 브라우저·기기를 쓰면 여러 명으로 집계될 수 있다.
- 전체 참가자에는 방문만 한 사람, 게임 중인 사람, 게임 완료 후 아직 뽑지 않은 사람이 포함될 수 있다.
- 따라서 **62.22%는 미추첨 비율이며, 게임 완료 후 복주머니에서 이탈한 비율로 해석하지 않는다.**
- 행사가 진행 중이므로 이후 전체 누적 비율 변화만으로 UX 개선 효과를 단정하지 않는다.

## 개선 후 비교 기준

1. 배포 시각과 버전을 기록한다.
2. 동일한 참가자 정의와 행사 범위로 미추첨 비율을 다시 집계한다.
3. `참가자 생성 → 유효 게임 완료 → 첫 복주머니 추첨`을 나눠, 게임 완료 후 미추첨 인원을 별도로 확인한다.
4. 가능하면 개선 전·후 유입 참가자를 구분하고, 각 집단에 동일한 관찰 시간을 준 뒤 비교한다.
5. 운영 당첨·재고·게임권 규칙은 UX 변경 성과와 별도로 기록한다.
