검사 명령:

```sh
python scripts/phase3_preflight.py

```

첫 명령은 확정 수량·예산·형식을 검사하고 미정 항목을 출력한다. 두 번째는 미정·증거 누락이 있으면 실패한다. 이는 **문서 검사**이며 실제 인프라 상태·승인의 진위·배포 안전성을 증명하거나 서버 설정을 바꾸지 않는다.
