# 랭킹·게임권 화면 보완 및 전체 참가자 테스트 모드

2026-09-26 사용자 요청. 작업 브랜치: `codex/ranking-ticket-ui`.

## 화면 변경

- 중앙 상단 로고는 홈 링크로 동작한다. 기존 라우터를 사용하며 새 탭 열기도 지원한다.
- 게임권이 없는 일반 상태에서는 시작 버튼이 `친구에게 공유하고 게임권 받기`로 바뀌고 초대 화면으로 이동한다. 행사 중단·종료 및 진행 중 게임 복원 규칙을 유지한다.
- 랭킹 상단을 TOP3 선물(1위 5만원·2위 3만원·3위 1만원)로 교체했다.
- 내 순위·최고 점수·현재 버전 랭킹에 기록이 있는 참가자 수를 표시한다.
- 시간 차이는 최고점 세션의 실제 `valid_ticks / 60`으로 계산한다. 점수는 코인 보너스를 포함하므로 시간순과 점수순은 다를 수 있다. 동점 3위는 기록 달성 시각, 참가자 ID 순으로 정한 대표 기록과 비교한다.
- 랭킹 화면에서 이전 규칙 수령 요청 및 합성 테스트 입력 카드를 제거했다. 서버에 저장된 접수 기록은 보존한다.

## 테스트 기간의 무제한 플레이

- 사용자가 특정 브라우저 방식 취소 후 **모든 참가자** 적용을 요청했다.
- `PREVIEW_UNLIMITED_PLAY=true`이면 local/test/preview의 활성 합성 참가자 모두 게임권 차감 없이 플레이한다. 기본값은 false다.
- 참가자 ID 허용 목록은 더 이상 사용하지 않는다. Vercel의 이전 참가자 ID 설정도 제거한다.
- 무료 게임 장애 시 환급을 새로 발행하지 않는다. 복주머니 1회, 차단·행사 상태·세션 검증은 유지한다.
- 테스트를 마치면 환경변수를 false로 바꾸고 재배포해 일반 게임권 방식으로 복귀한다.

- 여러 참가자의 무료 플레이, 요청 본문 조작 거부, 무료 세션 무환급, 테스트 모드 해제, 실제 시간·동점·게임 버전 격리를 검증했다.
- 로컬 브라우저에서 TOP3 선물·4위/450점/1,234명·12.3초 차이 예시와 로고 홈 이동을 확인했다. 예시 데이터는 `.local` 검토 서버 전용이며 배포 데이터에 추가하지 않는다.
- 원격 부하 테스트는 실행하지 않는다.
