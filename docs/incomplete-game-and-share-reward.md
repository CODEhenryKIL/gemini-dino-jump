# 미완료 게임 무효화와 최초 공유 보상

> 2026-09-27 최신 결정: 초대권은 카카오 전송 성공 웹훅 확인으로만 지급한다. 이전 유효 방문 보상과 최초 2회 공유창 보너스 규칙은 폐기한다. 최대 3장·10시간 대기는 유지한다. 수령 정보 공유 확인도 웹훅을 사용한다. 상세: [카카오 공유 설정](kakao-share-setup.md).

- 게임 화면에 들어갈 때 완료되지 않은 게임이 확인되면 자동으로 무효 처리하고 새 게임을 시작한다.
- 실제로 차감된 게임권만 원래 종류로 한 번 복구한다. 무료·무제한 게임은 게임권을 새로 만들지 않는다.
- 이미 완료된 게임과 검증 결과는 보존한다.
- 참가자별 최초 두 번의 친구 초대 공유는 카카오 공유 시도 또는 네이티브 공유창 완료가 확인되면 초대권을 한 장씩 지급한다.
- 복사·취소·실패는 공유 보상으로 인정하지 않는다.
- 초대권 보유 상한 3장과 10시간 추가 적립 대기 규칙은 그대로 적용한다.

## 적용 메모

- 로컬 테스트 DB와 로컬 브라우저 데모 DB에는 `20260927140000` 마이그레이션을 적용했다.
- 원격 Preview 배포 전에는 같은 마이그레이션을 원격 개발 DB에 먼저 적용해야 한다.
- 원격 운영 데이터와 배포는 이 변경 작업에서 건드리지 않았다.
