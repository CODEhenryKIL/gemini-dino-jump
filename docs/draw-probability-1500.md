# 향후 총 1,500회 추첨 확률 변경

- 사용자 확정: 1인 최대 10회 재뽑기를 포함하여 앞으로 총 1,500회 추첨. 기존 참여 인원·추첨 수는 새 분모에서 제외.
- 적용 시점의 남은 실제 경품 전부를 1,500개 미사용 자리 안에 포함. 나머지는 Gemini 혜택.
- 첫 회 상품별 확률 = 남은 상품 수량 / 1,500. 이후 남은 자리에서 균등 비복원 추첨.
- 기존 당첨·수령·게임·뽑기권·추첨판 행은 변경하지 않음. 101점 자격, 1인 최대 10회 유지.
- 1,500회 소진 후에도 Gemini 혜택만 제공하며 추첨 가능.

## 적용

1. 변수 추첨 횟수 마이그레이션 적용. 기존 3,000회 정책과 호환.
2. 새 서버 배포 및 정식 주소 확인.
3. `docs/sql/activate-draw-pool-1500.sql`로 운영 전환 잠금 → 추첨 잠금을 획득하고 원자적으로 변경.
4. 기존 3,000회 정책은 `draw_pool_policy_history`에 보존. 기존 행들의 해시가 동일한지 트랜잭션 내 검증.
5. 같은 SQL 재실행 시 기간·자리·수량을 다시 채우지 않음. 다른 정책에서 무단 전환 불가.
6. `docs/sql/draw-pool-current-odds.sql`로 실제 남은 자리와 회당 확률 확인.

## 검증 및 증거

1500/3000회 소진, 잘못된 정책 차단, 구버전 차단, 기존 결과 재조회, 3000→1500 전환 및 중복 적용 검증.
운영 적용 결과는 `docs/evidence/draw-probability-1500-20261001.json`에 기록.
숫자 범위 외 동작·DB 보존 원칙은 `docs/draw-probability-3000.md` 참고.
