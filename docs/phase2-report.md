## 관리자 부분 실패·로그인 복구 보완

- 관리자 세션 확인과 통계·수령·TOP3·장애 목록 조회를 구분했다. 일부 목록이 실패하면 성공한 영역은 유지하고 실패한 항목 이름과 다시 불러오기 버튼을 표시한다. 임시 조회 실패 때문에 유효한 관리자 로그인 값을 지우지 않는다.
- 관리자 요청의 401과 관리자 명단 확인의 403에서는 로그인으로 복귀하고 저장된 인증값·권한·연락정보 DOM을 제거한다. 인증 상태가 바뀐 뒤 늦게 도착한 이전 응답은 렌더링하지 않는다. 일반 503은 로그인 만료로 취급하지 않는다.
- 로그인 중 버튼·Enter 중복 요청을 막고, 권한이 없는 분석 영역은 숨긴다. 기존 서버 권한 검사와 Supabase 인증 설정·토큰 수명은 변경하지 않았다. 참고한 인증 계약: [Supabase 세션 문서](https://supabase.com/docs/guides/auth/sessions).
- 실제 관리자 HTML/JS를 임시 localhost에서 실행하되 응답은 전부 합성 fixture로 제공했다. 통계 503 + 다른 목록 정상 → 오류 안내와 수령·TOP3 표시 → 다시 불러오기 성공 → 다음 조회 401 → 로그인 복귀와 연락정보 제거를 Chromium으로 확인했다. 콘솔 오류·경고는 없었다. 원격 관리자 전체 로그인·업무 검증을 대신하는 증거로 쓰지 않는다.
- 새 비동기 행동 회귀 5개를 포함한 전체 Node **105개** 통과. 임시 서버와 fixture는 검증 후 정리했다. 부하·원격 권한·실개인정보·실지급 변경은 없다.
- `f50c5fd` Preview가 READY이며 health의 `database=ready`·`synthetic_only=true`를 확인했다. 원격에서 받은 `/js/admin.js`와 검증한 로컬 파일이 바이트 단위로 일치한다. 실제 원격 브라우저의 관리자 로그인 화면 진입은 확인했으며, 로그인 후 모든 업무 조작의 원격 검증은 아직 남아 있다.

## 기존 당첨 수령 기능 확인·수령함 복귀 보완

- `f50c5fd` Preview의 기존 합성 당첨 기록 한 건을 재사용했다. Preview API **17회 순차 호출**과 기존 합성 관리자 로그인 1회로 확인했으며, 참가자·재고 추가와 부하 테스트는 실행하지 않았다. 1차 부하 예산 파일의 해시도 전후 동일하다.
- 학교 누락·잘못된 연락처 거절 → 긁기 완료 저장 → 합성 수령 접수 → 동일 요청 재전송 → 재접속 조회를 확인했다. 다른 참가자의 접수는 404로 거절되고, 다른 주머니 번호를 다시 보내도 기존 추첨 ID·선택·결과가 유지됐다.
- 관리자 API에서 접수 내용을 읽고 해당 테스트 건만 `PENDING_REVIEW`로 변경했다. 이전 버전으로 덮어쓰려는 요청은 409로 거절됐다. 참가자 조회에도 확인 대기 상태가 반영됐다. DB에서 연락정보 1건·접수 이벤트 1건·관리자 변경 이력 1건과 재고 `RESERVED`를 확인했다. 지급 완료와 실제 연락·전달은 처리하지 않았다.
- 수령함에 앱 복귀·다른 탭 알림을 받는 `updateState`를 연결했다. 조회 실패 시 기존 카드를 유지하고 다시 불러오기 버튼을 제공하며, 같은 화면의 오래된 응답이 새 상태를 덮지 않게 했다. 입력 모달은 별도 DOM에 유지된다.
- 전체 Node **108개** 통과. 실제 수령함 모듈을 합성 응답으로 실행한 로컬 Chromium에서 정보 접수 → 확인 대기 갱신 → 일시 실패 시 카드 유지 → 다시 불러오기 성공을 확인했다. 원격 확인은 API 흐름이며 원격 브라우저 당첨·수령 전체 E2E를 대신하지 않는다.
- 수령함 복귀 보완은 아래 최신 배포 근거를 갱신하기 전까지 로컬 검증 상태다. 실기기·네이티브 공유·전체 앱 반복 플레이와 부하 보류 상태는 그대로다.

3. [로컬 브라우저 프레임·10회 엔진 정리 측정](phase2-browser-performance.md)을 완료했다. 빈 RAF도 약 30Hz인 IAB 환경에서 스테이지/부활 경계 지연 증가나 listener/RAF 잔류는 관측하지 않았다. 10회 완전 플레이, 전체 화면 애니메이션, 실기기·인앱 브라우저·네이티브 공유는 추가 검증 범위다. HTTP 테스트로 모바일 FPS 통과를 대신하지 않는다.
4. 실제 경품/확률/재고/기간, 대학생 인증 방식, 개인정보 안내, 동점 최종 수상 규칙, Google 공식 혜택은 3차 확정.
5. 4.26 체험담·사진 예시는 실자료를 받아 확정한다. Notion 원문 CTA 수정·게시 여부와 경유 추적 승인도 별도로 확인한다.
