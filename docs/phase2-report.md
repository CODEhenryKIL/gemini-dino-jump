### 실제 로컬 브라우저

Codex 내장 Chromium, 로컬 Python 서버 + 실제 로컬 PostgreSQL. 원격 성능 또는 실물 휴대폰 결과가 아니다.

- 최초 준비 → 홈 → 게임권 소비 → v2 정상 충돌 32점 → 서버 검증 → 1위 결과 표시.
- 2번 복주머니 선택 → 미당첨 확정 → 긁기 보조 버튼 → Gemini 안내.
- 새로고침 후 같은 참가자·게임권 잔액 복원.
- 혜택 화면의 공부 가이드 링크 실제 클릭. 서버 DB에서 `content_clicked` 확인.
- 로딩 데이터/연출/화면 준비, 게임 승인/완료, 추첨 확정/화면 공개, 보조 긁기, 가이드 카드 노출이 각각 저장됨을 확인.
- 혜택 화면 320/390/768/1440px에서 가로 넘침 없음. 정상 `localhost:3103` 흐름의 콘솔 오류·경고 없음.
- 이전 테스트의 다른 pepper로 생성된 쿠키는 401 복구 안내를 보였으며, 임의 새 참가자로 바꾸지 않았다.
- 새 로컬 참가자로 플레이 → 0이 아닌 점수에서 홈으로 이탈 → 새로고침 → 같은 게임 이어하기 → 저장된 2점부터 재개 → 32점 정상 종료·서버 승인까지 확인했다. 기본권은 추가 지급되지 않았다.
- 초대권은 로컬 합성 친구의 정상 유효 방문 API로 적립하고, 복귀한 브라우저에서 지급/사용량 갱신을 확인했다.
- 새 참가자가 테스트 커피에 당첨된 경로에서, 긁기 전 실제 접근성 트리에 경품명이 없고 Enter로 공개한 뒤 나타나는 것을 확인했다. 공개 후 키보드 초점도 다음 CTA로 이동하도록 보완했다.
- 로컬 브라우저 DB에 수령 상태 migration이 누락된 것을 발견해 적용했다. 정보 미입력 시 `정보 입력 대기`, 확인란 누락/잘못된 합성 연락처 제출 시 폼·입력 보존, 정상 합성 접수 후 `정보 접수` 표시와 새로고침 복원, 이후 Gemini 이동을 실제 화면에서 확인했다.
- iPhone Safari·Android·카카오톡/Instagram 인앱 브라우저 실기기와 실제 네이티브 공유는 아직 검증하지 않았다.
