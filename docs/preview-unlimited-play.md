# 지정 참가자의 무제한 테스트 플레이

사용자 요청(2026-09-26): 현재 브라우저의 참가자만 게임을 무제한으로 재도전할 수 있게 설정한다. 일반 참가자의 기본권·초대권, 복주머니 1회 규칙은 유지한다.

## 적용 방식

- 서버 전용 `PREVIEW_UNLIMITED_PARTICIPANT_IDS`에 지정한 참가자만 허용한다. 기본값은 빈 목록이며, API 요청이나 브라우저 저장소 값으로 권한을 부여할 수 없다.
- 인증된 합성 테스트 참가자에게만 적용한다. 참가자 차단·행사 일시 중지·게임 검증·중복 세션 방지 규칙을 유지한다.
- 허용 참가자의 게임은 기본권과 초대권을 소모하지 않는다. 차감하지 않은 게임에는 장애 환급으로 권리를 추가하지 않는다.
- 참가자 본인의 API 응답에 `tickets.unlimited_play`를 표시하고, 해당 브라우저의 홈·상단 게임권 표시를 `무제한`으로 바꾼다. 허용 목록 전체는 공개 설정에 포함하지 않는다.
- 복주머니·추첨·수령·초대 보상의 지급 규칙은 변경하지 않는다. 실제 경품은 계속 비활성인 Preview 환경이다.

## 브라우저 식별과 해제

- 현재 브라우저에서 실행한 초대 링크 복사 기록과 서버의 유일한 대응 참가자를 대조해 식별했다. 개인 참가자 ID와 배포용 설정 파일은 `.local`에 보관하고 Git에 올리지 않는다.
- 쿠키를 삭제하거나 다른 브라우저/시크릿 모드로 접속하면 별도 참가자가 될 수 있어 자동으로 권한이 이어지지 않는다.
- 해제하려면 서버 허용 목록에서 해당 ID를 제거하고 재배포한다. 이미 시작된 무료 게임이 추후 장애 처리되더라도 기존 차감 없음 표시를 기준으로 잔액을 보호한다.
- DB 스키마나 기존 참가자 잔액을 일괄 변경하지 않는다.
