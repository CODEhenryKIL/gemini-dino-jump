# 100점 이하 재도전 — 2026-09-27

- 서버 검증을 통과한 최종 점수가 100점 이하이면 사용한 게임권을 같은 종류로 환급한다. 101점부터 차감하며 무료/무제한 게임에는 추가권을 발행하지 않는다. 코인과 부활 감점을 포함한 최종 점수 기준이다.
- 초대권 환급은 기존 쿨다운 시각과 보유 한도를 유지하며, 중복 종료 요청에 중복 환급하지 않는다. 원장은 LOW_SCORE_REFUND로 구분한다.
- 결과 화면: 한 판 더 하기(잔여권/무제한/100점 이하) → 친구한테 공유하고 한 판 더 하기 → 복주머니 확인하기. 재도전은 기존 조작 가이드를 거친다.

## 101점 추첨 자격·Gemini 재도전 수정 — 2026-09-30

브랜치: `fix/share-retry-score-gate-20260930`. 2026-09-30 11:28:13 KST 정식 주소 반영을 확인했다. [배포 검증 기록](evidence/share-retry-deployment-20260930.md) 참조.

### 확인한 문제

- 기존에는 100점 이하 게임권 환급과 첫 추첨 자격이 독립적이어서 저점수 완료만으로도 추첨이 가능했다.
- Gemini 결과 이후에도 랭킹·친구초대 등 일부 재도전 경로는 GAME만 요청했다.
- BOTH 보상으로 뽑기권을 받아도 결과 화면 하단 고정 버튼은 게임 재시작만 우선 표시했다.

### 반영 내용

- 공유 문구를 `공유하고 한 판 더`로 통일한다.
- 현재 행사에서 서버 검증 최종 점수 101점 이상 완료 이력이 있어야 새 추첨이 가능하다. 0·99·100점만 완료한 경우 서버가 신규 추첨을 거부한다.
- 이번 판이 100점 이하이면 `다시 한번 도전해보세요!` 결과 화면으로 이동한다. 기존 게임권 환급 규칙은 유지한다.
- 과거 101점 이상 기록으로 얻은 자격은 유지한다. 이후 낮은 점수가 나와도 이미 적립된 뽑기권은 사용할 수 있다.
- 기존 저점수 참가자의 당첨·추첨 기록·원장은 삭제하지 않는다. 새로운 추첨은 101점 달성 후 열리며 기존 실제 당첨과 수령 접수는 보존한다.
- Gemini 이후 새 재도전 공유는 서버에서도 BOTH로 정규화한다. 게임권 3장·쿨다운·뽑기 10회는 각각 검사한다.
- 전송 확인 후 `한 번 더 뽑기`와 `한 판 더 하기`를 제공한다. 게임권 적립 제한 중에는 뽑기권만 추가한다.
- 이미 저장된 구버전 공유 요청은 원래 계약을 유지한다. 배포 전 생성된 GAME/DRAW 요청은 최대 30분 전환기 동안 해당 보상만 줄 수 있다.
