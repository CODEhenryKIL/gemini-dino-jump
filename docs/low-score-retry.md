# 100점 이하 재도전 — 2026-09-27

- 서버 검증을 통과한 최종 점수가 100점 이하이면 사용한 게임권을 같은 종류로 환급한다. 101점부터 차감하며 무료/무제한 게임에는 추가권을 발행하지 않는다. 코인과 부활 감점을 포함한 최종 점수 기준이다.
- 초대권 환급은 기존 쿨다운 시각과 보유 한도를 유지하며, 중복 종료 요청에 중복 환급하지 않는다. 원장은 LOW_SCORE_REFUND로 구분한다.
- 결과 화면: 한 판 더 하기(잔여권/무제한/100점 이하) → 친구한테 공유하고 한 판 더 하기 → 복주머니 확인하기. 재도전은 기존 조작 가이드를 거친다.
- TOP3 결과에는 짧은 4색 폭죽 효과를 한 번 표시한다. 클릭을 막지 않으며 움직임 최소화 설정에서는 생략한다.
- 로컬 DB migration 20260927090000 적용 및 3109 서버 재시작. 원격 배포 시 migration을 먼저 적용해야 한다.
- 검증: 프론트 189개, 서버 Phase1 32개·Phase2 및 동시성 14개, 마이그레이션·스키마 8개 통과. 로컬 결과 화면 순서와 서버 health 확인.
- 이번 변경은 로컬 반영이며, 배포 중인 베타의 무제한 설정은 유지한다.
