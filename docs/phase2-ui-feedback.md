## 1. 초기 로딩 연출

- 현재 로딩 연출에 대한 사용자 평가: 완성도가 부족하고 지나치게 단순해 보인다.
- 영상 또는 애니메이션으로 더 세련되고 완성도 있게 개선한다. 구체적인 매체·연출 방식은 아직 정하지 않았다.
- 폰트 등 시각 요소에 Google의 색상을 반영한다.
- 현재 로딩이 너무 짧으므로 우선 약 **5초**로 늘리는 방향을 검토한다. 사용자는 “한 5초로 늘려도 될 듯 일단”이라고 제안했다.

## 2. 메인 화면의 팀 Gemini 로고

- 팀 Gemini 로고가 두 개 표시되는 중복을 해소한다.
- 메인 화면에는 중복 로고가 나오지 않게 한다.

## 3. 홈 화면 구성·문구

1. 최상단 바로 아래에 다음 문구를 배치한다.

2. 현재 작은 글씨로 표시되는 **“지금 사용 가능 1장”** 부분과 해당 영역의 **복주머니 관련 표시·설명**을 삭제한다.
3. 시작 버튼 문구를 **“게임 시작”**으로 바꾼다.
4. **“복주머니와 재도전”** 문구를 삭제한다.
5. 상단의 **“공룡 점프 / 어디까지 갈 수 있을까?”** 문구를 수정해 **Google AI로 만든 게임이라는 사실이 명확하게 드러나도록** 한다. 최종 문구는 아직 작성하지 않았다.

## 반영 결과

- 기존 원본 공룡과 팀 로고를 사용하는 5초 CSS 애니메이션으로 변경했다. Google 4색·공룡 점프·세 단계 문구 전환을 사용하며 별도 영상 다운로드나 라이브러리는 추가하지 않았다.
- 홈의 팀 로고는 공통 상단 한 개만 남겼다. 제목은 `Google AI로 만든 공룡 게임`, 행사 문구는 오타를 다듬은 `추억의 공룡 게임 한 판 하고 삼텐바이미 받자!`, 정상 시작 버튼은 `게임 시작`이다.
- 정상 상태의 사용 가능 안내, 복주머니 상태 설명, `복주머니와 재도전` 설명 카드를 제거했다. 실제 복주머니 버튼과 게임 복원·장애/권리 부족·행사 상태 동작은 유지한다.
- 로딩 동안 배경 앱의 키보드 조작을 막고 완료 뒤 해제한다. 실제 준비 지연은 연출 시간과 별도로 기다리며, 실패하면 쉬운 안내와 다시 연결을 제공한다.
- 기준과 제약은 저장소 `DESIGN.md`에 기록했다. 게임·DB·서버 규칙은 변경하지 않았다.

## 확인 결과

- 전체 Node 146개, 변경 JavaScript 문법·diff 검사 통과.
- 실제 앱 + 로컬 합성 API에서 연출 완료 약 5.0초와 별도의 데이터 준비 이벤트를 확인했다. 5초를 원격 서버 지연 수치로 해석하지 않는다.
- 390px 로딩 1초/2.5초/4.5초 장면, 320px 홈 가로 넘침 없음·단일 로고·시작 가이드, 연결 실패→다시 연결→홈 복귀를 확인했다.
- 로딩 단계의 대체 설명을 접근성 그룹에 제공하고, 재시도 중 상태 안내 → 성공 후 본문으로 키보드 포커스가 이동하는 것을 실제 브라우저에서 확인했다. 재시도 실패 시 버튼으로 돌아오는 동작도 회귀 검사에 포함했다.
- 모션 감소는 실제 CSS 미디어 규칙을 적용한 로컬 정적 시안으로 확인했다. OS 실기기의 모션 감소 설정 시험과 구분한다. 낮은 화면에서도 오류·재시도 영역까지 스크롤할 수 있다.
- 이번 작업에서 원격 부하 테스트·Production 배포는 실행하지 않는다.
- Preview 배포 READY, health의 `database=ready`, `environment=preview`, `synthetic_only=true`를 확인했다. HTML 차이는 Vercel이 끝에 추가한 피드백 스크립트 1개였다. 사용자 요청으로 추가 배포 파일·화면 검증은 중단했다.

- 이번 후속 수정은 로컬 반영 상태이며 개별 테스트·추가 배포는 실행하지 않았다. 위 Preview와 146개 테스트 결과는 이 수정 이전 버전의 기록이다. 남은 수정과 함께 한 번에 검증한다.

## 후속 수정 — 참여 설명과 타이포그래피

- 로딩의 작은 한 줄 설명을 3단계 참여 안내(공룡 게임 한 판 / 복주머니 열기 / 친구 초대로 한 번 더)로 교체했다. 단계 설명은 로딩 내내 표시한다.
- 로딩·홈의 글자별 무지개 색상, 과한 굵기·좁은 자간을 제거했다. 한국어 시스템 글꼴, 중간 굵기, 짙은 회색 본문과 Google 블루 강조로 정리했다. 로고 원본 색상과 4색 진행바는 유지한다.
- 로딩은 흰 배경·간결한 로고 배치로 정리하고 기존 공룡 홉은 유지했다. 로컬 수정 상태이며 자동 테스트·원격 배포는 일괄 반영 뒤 진행한다.

## 후속 수정 — 중앙 설명 애니메이션·로고 위치

- 팀 제미나이 로고를 로딩 하단 중앙으로 이동했다. 하단 행사·경품·대상·Preview 설명과 정적 3단계 목록을 제거했다.
- 기존 중앙 공룡 자리를 5초 설명 애니메이션으로 교체했다. 게임 장애물 넘기 → 복주머니 선택 → 복권 긁기 장면과 각 설명이 같은 자리에서 순서대로 전환된다.
- Google Gemini 로고·제목은 상단, 진행바·연결 상태는 애니메이션 바로 아래에 둔다. 모션 감소에서는 장면 없이 3단계 문구를 표시한다. 일괄 검증·배포는 보류한다.

## 최종 사용자 선택 — 로딩 고정 요소

- 앞선 하단 로고 이동 요청을 최신 선택으로 대체한다. 상단에 팀 제미나이 + Google Gemini 로고를 가로로 유지하고 하단 중복 로고는 두지 않는다.

- 로딩의 Preview 시안·경품 부가 안내는 제거한다. 홈 게임 규칙의 Preview 접두어도 제거한다. 중앙 게임·복주머니·긁기 설명 애니메이션은 유지한다.
- 운영 환경·실경품 설정은 변경하지 않는다. 개인정보 입력의 합성 정보 제한은 실제 운영 전환 작업과 함께 처리한다.

## 후속 수정 — 마지막 경품 쇼케이스

사용자 제공 경품표를 바탕으로 실제 제품 사진의 배경 제거 합성과 Sony 원본 PNG, 상품권 5종 카드를 추가했다. 마지막 장면에서 제품과 상품권이 순차 등장한다. 5초 길이를 유지하고 앞선 설명 장면의 시간을 조정했다. 출처·대표 이미지 가정·이미지 편집 프롬프트는 [경품 시각 기록](phase2-prize-visuals.md)에 보관했다. 로컬 반영이며 원격 배포·부하 테스트는 보류한다.

## 후속 수정 — 터치 중심 게임 가이드

- 조작 안내 줄글과 PC 안내를 4장 슬라이드로 교체: 화면/아래 버튼 터치 → 웃음 코인 +10점 → 하트 부활 → 랭킹 보상.
- 실제 공룡·웃음·하트 에셋을 사용한 짧은 CSS 애니메이션, 다음/이전과 좌우 스와이프, 하단 건너뛰기를 제공한다. 모션 감소 설정에서는 정적으로 표시한다.
- 마지막 장에 행사 최종 순위 보상(1위 5만원, 2위 3만원, 3위 1만원)과 기존 leaderboard API의 현재 TOP3·내 순위를 표시한다. 동점자를 포함하며 빈 기록/조회 실패/재시도를 구분한다.
- 최초 게임 진입 안내와 홈에서 다시 보는 안내를 모두 연결했다. 가이드를 열거나 넘기는 것만으로 게임권을 사용하지 않는다.
- 로컬 화면 서버의 랭킹 응답은 빈 기록이다. 실제 참가자 랭킹은 서버에 연결한 환경에서 표시된다.
- 사용자의 일괄 검증 요청에 따라 브라우저·회귀 테스트는 이후 진행한다. 기존 홈 가이드 테스트의 모듈 로딩 방식도 새 컴포넌트에 맞춰 검증 단계에서 갱신해야 한다. 배포·부하 테스트는 실행하지 않는다.

### 후속 조정 — 이전/닫기와 랭킹 가독성

- 하단 왼쪽을 이전 버튼으로 고정하고 첫 장에서는 비활성화한다. 닫기는 우측 상단 ×로 이동하며 Escape 닫기를 유지한다.
- 안내 본문 15px, 보조 설명 14px, 현재 TOP3 제목 17px, 랭킹 행 15px, 보상 금액 28px로 키웠다.
- `/__review/guide-ranking`은 로컬 서버만 제공하는 샘플이다. 실제 가이드 컴포넌트에 가상 닉네임·점수 3행과 내 순위 3위를 넣고 화면을 표시했다. DB와 운영 랭킹은 수정하지 않는다.
- JavaScript 문법과 diff 공백 오류, 요청된 샘플 화면의 표시를 확인했다. 전체 회귀·부하 테스트는 여전히 보류한다.
