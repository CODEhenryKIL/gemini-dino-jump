- 참여 자격: `게임은 누구나 참여할 수 있고, 경품 수령은 대학생을 대상으로 해요.`
- 복주머니: `첫 정상 게임 뒤 복주머니를 바로 열 수 있어요. 공유는 선택이며 추가 추첨은 없어요.`
- 초대 보상: `친구가 링크를 열고 화면이 보이는 상태에서 3초 이상 머문 뒤 한 번 누르면 방문을 확인해요.`
- TOP3: 현재 순위와 서버 점수 차이만 안내하고, 최종 경품 지급 순위와 동점 수상 기준은 이벤트 종료 시점에 확정된다고 표시한다.
- 수령: 정보 접수, 운영 확인, 연락 완료, 실제 지급 완료를 서로 다른 상태로 표시한다.
- Gemini: `대상·기간·가격·신청 조건은 공식 페이지의 최신 안내를 기준으로 확인해 주세요.`

## `4년 평균 4.26` 장문 콘텐츠 개요

실제 성적 증빙, 작성자 동의, 과목 구성, 계산 기준, Gemini 사용 기록이 제공되지 않았다. 아래는 증빙 확보 뒤 작성할 구조이며 현재 공개 본문이 아니다.

1. 작성자와 계산 기준: 재학 기간, 학점 체계, 평균 산식, 개인정보 공개 범위
2. 실제 학습 문제: 과목 유형별 어려움과 기존 방식
3. 사용 루틴: 자료 정리, 질문 작성, 검증, 복습 단계
4. 구체 사례: 입력 자료와 출력 결과를 익명화한 실제 예시
5. 한계와 검증: 틀린 답을 확인한 방법, 원자료 대조, 사용하지 않은 상황
6. 결과 근거: 성적표 등 승인된 증빙과 도구 사용 사이의 인과를 과장하지 않는 설명
7. 재현 가능한 체크리스트: 독자가 자신의 자료로 안전하게 시험하는 절차

증빙이 없으므로 GPA 4.26을 앱 제목, 배지, 성공 보장, 체험담으로 사용하지 않는다.

## Notion 내부 CTA 초안

아래 문구는 원문에 게시하지 않은 편집 제안이다.

- 위치: 각 공개 가이드의 마지막
- 제목: `Gemini 학생 혜택도 확인해 보세요`
- 설명: `대상과 기간, 신청 조건은 공식 페이지의 최신 안내를 확인해 주세요.`
- 버튼: `공식 혜택 페이지 열기`

게시 전에는 CTA 위치, 공식 URL, 운영 주체 승인, Notion 편집 권한을 Phase 3에서 확인한다.
