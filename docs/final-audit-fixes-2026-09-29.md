## 남아 있는 한계와 오픈 작업

1. **자동 플레이 완전 차단은 아니다.** 서버 물리 검증은 사람 조작을 증명하지 않는다. 이번 보완은 최종 경품 확정 전 검토·보류·감사 기록 절차다.
2. 새 코드의 배포와 실제 모바일 확대·안전 영역·키보드 확인, 수령용 나에게 보내기→접수 완료 실전송 확인이 남아 있다. 점프 선택 문제는 사용자가 이미 해결 확인했다.
3. 본행사 운영 영역·접속·재고 배정·승인·백업/롤백·외부 혜택/Notion 확인이 남아 있다. 기존 베타는 계속 별도 상태다.
4. 최종 부하 테스트는 사용자 요청대로 보류한다. 과거 테스트 결과를 새 버전의 부하 시험 완료로 간주하지 않는다.
5. 관리자 수령 목록 200건 제한, manifest 검사 공통화, DB 인덱스 권고는 기존 감사의 관찰 사항으로 남긴다. 개인정보 정리 도구는 관리자 목록의 200건 제한에 의존하지 않는다.
6. 마감 후 순위 확정 대기 30초는 현재 Vercel 최대 실행 30초와 함께 관리해야 한다. 실행 제한 변경 시 정산 기준을 재검토한다.

오픈 준비 상태와 실제 수행 기록은 [체크리스트](phase3-launch-checklist.md)에서 관리한다.
